# /tweak — ползунки, потом «запечь»

Скрипт `scripts/tweak_server.py` (рядом с этим файлом) поднимает локальный сервер, который отдаёт страницу
с внедрённой панелью `assets/tweak-panel.js`. **Сам файл, пока идут правки, не меняется** — панель
живёт только в браузере. Когда пользователь жмёт «Сохранить в файл», панель применяет правки к исходнику
и сервер перезаписывает HTML (и локальные CSS-файлы, если менялись цвета/масштабы в них), предварительно
сделав копию в `.tweak-backups/<дата-время>/`.

## Шаги

1. **Найди файл.** Путь — из аргумента. Если его нет: возьми HTML, над которым шла работа в этом разговоре;
   иначе поищи `*.html` в текущей папке и, если кандидатов несколько, спроси какой.
2. **Запусти сервер в фоне** (Bash с `run_in_background: true`):
   ```bash
   python3 "<папка этого скилла>/scripts/tweak_server.py" "<путь к html>"
   ```
   - Если страница подключает файлы выше своей папки (`../css/…`), добавь `--root <общая папка>`.
   - Сервер сам откроет браузер и напечатает строку `TWEAK_URL http://127.0.0.1:…`. Если порт занят —
     возьмёт следующий свободный. `--no-open` — не открывать браузер (тогда открой URL сам, например
     во встроенном браузере приложения).
3. **Дай пользователю ссылку и короткую шпаргалку** (ниже). Не пересказывай весь функционал.
4. **Жди.** Каждое сохранение печатает в вывод сервера `TWEAK_BAKED <файлы> (backup: …)`.
   Когда пользователь скажет, что закончил (или спросит, что поменялось), прочитай вывод сервера,
   покажи краткое резюме изменений (`diff -u <backup> <файл> | head -80`) и останови сервер.
5. **Пока панель открыта, не редактируй этот HTML сам.** Панель сверяет файл перед сохранением
   и откажется писать, если он изменился на диске. Если правка нужна — внеси её, затем попроси
   пользователя обновить страницу (несохранённые правки панели лежат в localStorage и восстановятся).

## Шпаргалка для пользователя

- **Общее** — масштаб шрифтов, отступов (padding/margin/gap) и скруглений на всей странице, в процентах.
  Двойной клик по ползунку — вернуть 100%.
- **Цвета** — все цвета из CSS страницы; клик по кружку заменяет цвет везде (вместе с его
  полупрозрачными вариантами), правый клик — вернуть исходный.
- **Элемент** → «Выбрать элемент»: клик выделяет элемент, ↑ — родитель. Размер текста, жирность,
  выравнивание, цвет текста и фона, отступы, скругление. Двойной клик — редактировать текст прямо на
  странице (Enter — готово, Shift+Enter — перенос строки, Esc — отмена). Delete / «Скрыть» — убрать элемент.
- ⌘Z — отменить, «Сбросить всё» — начать заново, Alt+T — спрятать/показать панель.
- **«Сохранить в файл»** — записывает всё в исходник, страница перезагружается уже с новым дизайном.

## Как это устроено (для отладки)

- Состояние правок: масштабы `type/space/radius`, карта замен цветов, и по-элементные правки
  (путь от `<body>` по индексам детей + тег + id для проверки). Живая страница каждый раз
  пересчитывается из **исходного** CSS + этих данных, и при сохранении те же функции применяются к сырому файлу.
- Масштабы переписывают значения в `px`/`rem` у `font-size`/`font`, `padding*`/`margin*`/`gap`,
  `border-*radius`, а также у CSS-переменных с «говорящими» именами (`--font-*`, `--text-*`, `--space*`,
  `--gap*`, `--radius*` и т.п.). `font-size` на `html`/`:root` не трогается, чтобы не удвоить rem.
- Правки элементов пишутся в его атрибут `style`; правка текста — в его содержимое; скрытые элементы
  при сохранении **удаляются** из файла.
- Файл пересобирается браузерным сериализатором: разметка та же, но форматирование атрибутов/сущностей
  может слегка нормализоваться. Исходник всегда лежит в `.tweak-backups/`.

## Ограничения

- Контент, который рисует JavaScript (React/Vue-рендер в рантайме), в исходнике отсутствует — такие
  правки не переносятся, панель сообщит «не удалось перенести правок: N».
- Tailwind через CDN: глобальные масштабы и палитра не действуют (стили генерируются скриптом),
  но правки конкретных элементов работают.
- Цвета в SVG-атрибутах (`fill="#…"`) и во внешних (не локальных) CSS палитра не видит.
- Нужен Python 3.7+ (только стандартная библиотека).
