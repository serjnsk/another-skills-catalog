# Типографика — шкала и правила (Apple HIG, раздел Typography)

Источник: developer.apple.com/design/human-interface-guidelines/typography.

## Минимумы и базовые размеры

| Платформа | По умолчанию | Минимум |
|---|---|---|
| iOS, iPadOS | **17 pt** | **11 pt** |
| macOS | **13 pt** | **10 pt** |
| tvOS | **29 pt** | **23 pt** |
| visionOS | **17 pt** | **12 pt** |
| watchOS | **16 pt** | **12 pt** |

- Поддерживайте увеличение текста минимум на **200 %** (watchOS — **140 %**): через Dynamic Type или свой UI.
- Тонкий кастомный шрифт → берите кегль **крупнее** рекомендованного.
- Избегайте начертаний Ultralight, Thin, Light, особенно в мелком тексте. Рабочие веса: Regular, Medium, Semibold, Bold.

## Иерархия
- Иерархию стройте весом, размером и цветом; сохраняйте её при любом размере шрифта.
- Минимум гарнитур — даже в сильно кастомном интерфейсе.
- При увеличении шрифта растёт важный контент; второстепенное (например, заголовки вкладок) не обязано расти.

## Системные шрифты
- **SF Pro** — системный шрифт iOS, iPadOS, macOS, tvOS, visionOS; **SF Compact** — watchOS (в компликациях — SF Compact Rounded). Есть SF Mono, SF Arabic/Armenian/Georgian/Hebrew, Rounded-варианты, ширины Condensed/Expanded, веса от Ultralight до Black.
- **New York (NY)** — серифная пара к SF (iOS, iPadOS, tvOS, watchOS; в macOS — только в Mac Catalyst).
- Шрифты вариативные, с динамическим оптическим размером (Text/Display сливаются в непрерывный дизайн) — в макетах отдельные «Text»/«Display» выбирать не нужно, но трекинг надо выставить по таблице ниже.
- SF Symbols имеют те же веса — подбирайте вес символа под соседний текст.
- Emphasized-варианты стилей (symbolic traits: `bold()`, `traitBold`) — веса Medium, Semibold, Bold или Heavy (см. колонку Emph.).
- Не встраивайте системные шрифты в приложение — берите через `Font.Design` (`.default`, `.serif` = NY и т.д.).

### Шрифт в HTML-прототипе
```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro", system-ui, sans-serif; /* SF */
font-family: ui-serif, "New York", Georgia, serif;                                             /* NY */
font-family: ui-rounded, "SF Pro Rounded", -apple-system, sans-serif;                          /* Rounded */
font-family: ui-monospace, "SF Mono", Menlo, monospace;                                        /* Mono */
```
1 pt = 1 CSS px при вьюпорте в точках (например, 393×852). Трекинг: `letter-spacing` в em = значение из таблицы / 1000.

## Кастомные шрифты
- Должны быть читаемыми на тех же минимумах; обязаны поддерживать Dynamic Type и Bold Text так же, как системные.

## Dynamic Type (iOS, iPadOS, tvOS, visionOS, watchOS; в macOS нет)
- Проверяйте вёрстку на всех размерах, включая Larger Accessibility Sizes (AX1–AX5).
- Значимые иконки растут вместе с текстом (SF Symbols масштабируются сами).
- Минимум обрезаний: на самом большом AX-размере показывайте столько же полезного текста, сколько на самом большом стандартном. В скроллируемых областях не обрезайте без возможности открыть полный текст; разрешайте многострочность.
- На крупных размерах перестраивайте строку в столбик: текст сверху, иконки/время — под ним; многоколоночный текст сводите в одну колонку.
- Главное остаётся вверху экрана при любом размере.
- visionOS: body и title жирнее, плюс стили Extra Large Title 1/2.
